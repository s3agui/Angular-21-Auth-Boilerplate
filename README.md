# Angular 21 Auth Frontend

## Live URL
https://angular-auth-cuerda.netlify.app/

## Backend API
https://backend-repo-node-mysql-auth-api.onrender.com

## API Documentation
https://backend-repo-node-mysql-auth-api.onrender.com/api-docs

## Features
- Email sign up and verification
- JWT authentication with refresh tokens
- Role based authorization (User & Admin)
- Forgot password and reset password
- View and update profile
- Admin section for managing accounts

## Stage A - Fake Backend
Branch: main
Enable fakeBackendProvider in app.module.ts

## Stage B - Real Backend  
Branch: real-backend
Backend: Node.js + MySQL on Render

## Setup Instructions
1. Clone the repo
2. Run npm install
3. Run npm start
4. Open http://localhost:4200

## Tech Stack
- Angular 17
- Bootstrap 5
- JWT Authentication
- TypeScript
